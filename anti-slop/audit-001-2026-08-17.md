## Blok HIGH (R-03: mobile rusak / kontrol tak terjangkau)

1. **Landing Navbar kehilangan semua navigasi section di mobile, tanpa pengganti**
   `src/components/landing/Navbar.module.css:70-74` (`@media (max-width:768px){ .navLinks { display:none } }`) — satu-satunya link Home/Templates/Pricing/FAQ hilang di bawah 768px; tidak ada hamburger/menu sama sekali di landing. `ScrollDots` juga dihapus di bawah 1023px (`ScrollDots.module.css:58-62`). Pengunjung mobile tidak punya cara menuju section selain scroll manual. R-03 (nav mobile).

2. **Navbar row overflow 375px**
   `Navbar.module.css:13-18,25-29` — `gap:48px`, logo (intrinsik ~130px), locale switcher (~76px), login (~78px) ≈ 380px > ~335px usable. Sisi kanan (login/avatar) terdorong keluar viewport. R-03 (horizontal overflow).

3. **TemplateShowcase: tombol Pratinjau/Gunakan hanya muncul saat hover — tak terjangkau di touch**
   `src/components/landing/TemplateShowcase.module.css:115-131` — `.cardOverlay { opacity:0 }` hanya menjadi `opacity:1` saat `.cardPreviewArea:hover`. Di phone tidak ada hover, CTA utama showcase tidak pernah muncul. R-03 (hover-only tanpa tap equivalent).

4. **WorkspaceCard: menu tiga titik terpotong `overflow-hidden` thumbnail, Delete tak bisa dijangkau di mobile**
   `src/components/dashboard/components/WorkspaceCard.tsx:80` (thumbnail `overflow-hidden`) + `:110` (menu `absolute right-0 top-full`). Menu 7 item (~219px) mulai ~42px dari atas thumbnail 220px (mobile) → baris terbawah (Delete) terpotong penuh di mobile, ~90% di sm+. R-03 (clipping kontrol).

5. **Editor: header kanan overflow 375px — pill Draft/Live + Publish terpotong**
   `src/components/dashboard/Editor.tsx:616-674` — cluster kanan `w-1/3` (~125px) menampung 5 kontrol (pill status ~84px + history + preview + save + publish ≈ 380px min-content); parent `overflow-hidden` (Editor.tsx:595) memotong sisi kanan. CTA utama (Publish) terancam. R-03.

6. **Editor: quick-action toolbar (edit/reorder/delete) hanya terpicu `onMouseMove` — mati di touch**
   `src/components/dashboard/editor/EditorCenterCanvas.tsx:204-205,213-279` — toolbar hanya render saat `hoveredActionCard` diset, yang hanya diset dari `handlePreviewMouseMove` (`onMouseMove`). Perangkat touch tidak pernah memicu; aksi edit utama di canvas tidak ada di mobile. R-03.

7. **Editor: panning canvas hanya wheel/mouse — konten zoom yang overflow tak terjangkau touch**
   `EditorCenterCanvas.tsx:143-159` + `Editor.tsx:300-319` — pan via `onWheel`/`onMouseDown`/`onMouseMove` (`e.deltaX`, `e.movementX`). Di 100% zoom frame device (390px) > viewport 375px dengan `overflow-hidden`, tanpa touch pan; tidak ada `touch-action`. R-03 (konten terpotong tanpa akses).

8. **Admin: tabel templates overflow tanpa containment — konten keluar card, page ikut scroll horizontal**
   `src/app/[locale]/admin/templates/page.tsx:32,40,53,85,93,116` — card `rounded-2xl bg-surface p-6` tanpa `overflow-x-auto`; tabel berisi UUID `font-mono` (`:53`) dan `min-w-[170px]` (`:116`). Min-content tabel ~700-800px > 375px; outer menjadi scroll 2 sumbu dan card chrome rusak. R-03.

9. **Admin blocklist: tombol hapus berupa ikon 13px tanpa padding**
   `src/components/admin/BlocklistClientView.tsx:139-146` — touch area = glyph 13px, `hover`-only, tanpa `:active`. R-03 (tap target).

10. **Designer: tidak ada state mobile sama sekali — sidebar 280px selalu render, konten menyusut ke ~55px**
    `src/app/[locale]/designer/layout.tsx:24-28` + `src/components/designer/DesignerSidebar.tsx:14` — shell `flex ... gap-4 p-3` dengan sidebar `w-[280px] shrink-0` tanpa drawer/mobile top bar. Di 375px: 375−24−16−280 = 55px untuk `<main>`. Squeezed desktop, bukan layout mobile. R-03.

11. **SubmissionForm: header judul/back-link menabrak tombol aksi `shrink-0` di 375px**
    `src/components/designer/SubmissionForm.tsx:106-116` — dua tombol (~202px) `shrink-0` tidak pernah wrap; kolom kiri dapat ~109px dan judul/back overflow menabrak tombol. R-03.

12. **Auth: shell `100vh` + `overflow:hidden` — bagian bawah form tak terjangkau di mobile browser**
    `src/components/auth/AuthSplitLayout.module.css:3-6` — `.loginPageContainer { height:100vh; overflow:hidden }`, `.loginRight` satu-satunya scroller. `100vh` meliputi area di belakang browser toolbar; submit button + footer link tersembunyi di bawah fold tanpa scroll. Harus `100dvh`. R-03 (100vh section).
